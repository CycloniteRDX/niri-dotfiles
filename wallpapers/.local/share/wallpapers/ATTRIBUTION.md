# Midnight Circuit

`midnight-circuit.svg` is an original vector wallpaper created for this
dotfiles project. It uses no external image, font, logo, character, or
machine-specific data.

The asset is dedicated to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).

Palette:

- background: `#0b0f17`;
- surface: `#121824`;
- cyan accent: `#5ce1e6`;
- magenta accent: `#f05adf`;
- foreground: `#dce7f2`.
