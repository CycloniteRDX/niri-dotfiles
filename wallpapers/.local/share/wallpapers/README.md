# Wallpapers

`midnight-circuit.svg` is the reviewed portable wallpaper. It is a small,
editable 1920×1080 vector using the project's dark cyan/fuchsia palette.
`swaybg` scales it with `fill` on each output and falls back to `#0b0f17` when
the file is unavailable.

See `ATTRIBUTION.md` for authorship and license information. Additional assets
must be non-secret, redistributable, documented, and optimized before they are
committed.
